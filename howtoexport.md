# Setup guide
## 1. export from (Samsung) TV to USB Drive
## 2. copy zip from USB Drive to PC
## 3. use [chansort](https://github.com/PredatH0r/ChanSort) to export channel list to excel (copy, paste and then save as csv)
## 4. put `channels.csv` in the same folder as this program
## 5. run this program via `go run main.go` or `go build` and then the executable
## 6. profit (Server runs on `localhost:8080`)
